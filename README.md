# Python Area Calculator
A beginner python program that calculates the area of different shapes.

## About the project
This program calculates the area of different shapes by taking the required measurements as input from the user.

The shapes included in this project are:
-Square
-Rectangle
-Circle
-Triangle

## Concepts used

-'input()'
-'print()'
-variables
-Arithmetic operations

## What I learned

This project helped me practice taking user input, storing values in variables, and using mathematical formulas in python to calculate areas.
