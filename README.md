# Python Area Calculator
A beginner python program that calculates the area of different shapes.

## About the project
This program calculates the area of different shapes by taking the required measurements as input from the user.

The shapes included in this project are:
-Square
-Rectangle
-Circle
-Triangle
The user can select a shape using the menu , entering the required measurements ,and view the calculated area.
The program uses a loop to allow users to calculate the area of multiple shapes without restarting it.Users can also choose to exit the program.
